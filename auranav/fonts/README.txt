Noto Sans Regular glyph ranges

The Mapbox/MapLibre SDF PBF files in this directory were downloaded from
https://demotiles.maplibre.org/font/Noto%20Sans%20Regular/ on 2026-09-18.
The MapLibre demotiles project states that its PBFs were generated using the
scripts and source fonts from https://github.com/openmaptiles/fonts.

Noto is licensed under the SIL Open Font License 1.1. The complete license is
included as ../OFL.txt.

Only range 0-255 (current chart labels) is packaged so the application does not
contact a font server while offline. Chart symbols are drawn as images rather
than glyphs, so no other range is needed.

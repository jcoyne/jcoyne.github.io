Swim Top 10 report

Builds a top-10 report for each event from mnswimandvibe.com and downloads it as an HTML file.

  1. Drag this button to your bookmarks bar: Swim Top 10
  2. Open mnswimandvibe.com/mantaray.
  3. Click the Swim Top 10 bookmark. A panel appears in the top-right corner.
  4. Choose the season, set the team code (leave it blank for statewide), and click Download report. It takes a minute or so to fetch every event.
Why not right here? The swim site only answers requests from its own pages, so the script has to run there.

If bookmarks aren't an option, copy the script, open DevTools > Console on the swim site, paste it, and press Enter.
